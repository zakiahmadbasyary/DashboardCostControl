# Folder Template Excel CAPEX

Simpan file template Excel (.xlsx) Anda di dalam folder ini:
`apps/dashboard-capex/public/templates/`

Berikut daftar nama file template yang didukung sesuai kategori upload:

| Kategori Upload | Nama File Utama | Nama File Alternatif yang Didukung |
| :--- | :--- | :--- |
| **Data Created** | `template_created.xlsx` | `Data_Created.xlsx` |
| **Data PO** | `template_po.xlsx` | `Data_PO.xlsx` |
| **Data Budget** | `template_budget.xlsx` | `Data_Budget.xlsx` |
| **Data Purchasing** | `template_purchasing.xlsx` | `Data_Purchasing.xlsx` |
| **Data Kategori** | `template_kategori.xlsx` | `Data_Kategori.xlsx` |
| **User Approver** | `template_user_approver.xlsx` | `Data_Approver.xlsx`, `template_approver.xlsx` |
| **Master Cost Center** | `template_cost_center.xlsx` | `Data_Cost_Center.xlsx`, `data_cost_center.xlsx` |

> Jika file fisik template Anda diletakkan di folder ini, sistem akan otomatis mengunduh file Excel kustom milik Anda saat tombol **"Unduh Template Excel"** diklik di dashboard admin.
